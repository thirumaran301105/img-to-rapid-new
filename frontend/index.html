Paper and placement

Look down at the paper. Pick the work object axis that runs left to right, then say where the page's bottom-left corner is in work object millimetres. Use the test pattern to check.

Tool and work object

Pasting your tooldata and wobjdata sets the names, tool length and which way the work object's Z points (this decides the tool direction and the pen-up direction).

Speed and pen

Dry run keeps the pen in the air above the paper, so you can watch the whole drawing before it touches anything.
